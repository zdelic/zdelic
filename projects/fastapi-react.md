# FastAPI + React CRM

## API-First Project Management Application

A modern full-stack CRM-style application built with FastAPI on the backend and React / TypeScript on the frontend.

---

## Purpose

The project demonstrates an API-first architecture outside the Laravel/PHP ecosystem and shows how the same business-application patterns can be implemented with Python.

---

## Core Features

- project management
- structure management
- task management
- progress statistics
- REST API
- data validation with Pydantic
- SQLAlchemy data layer
- modern React / TypeScript frontend
- SQLite by default with PostgreSQL as an option

---

## Architecture

```text
React + TypeScript
       │
       │ REST / JSON
       ▼
     FastAPI
       │
       ├── Pydantic schemas
       ├── application routes
       └── SQLAlchemy ORM
       │
       ▼
SQLite / PostgreSQL
```

---

## Technology Stack

- **Backend:** FastAPI, Python
- **ORM:** SQLAlchemy
- **Validation:** Pydantic
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Database:** SQLite / PostgreSQL
- **API Documentation:** OpenAPI / Swagger via FastAPI
